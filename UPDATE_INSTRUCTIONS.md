## Как применить к существующему GitHub-репозиторию

1. Сделай `git pull` в локальном клоне существующего проекта `dn-collectibles`.
2. Распакуй `DN_Collectibles_Roadmap_update_only.zip` и **скопируй содержимое** (папки `src/` и `public/`) в корень проекта с заменой указанных файлов. Не удаляй остальные файлы репозитория и workflow деплоя.
3. Проверь `git diff` и `git status`.
4. Выполни `npm install`, `npm run typecheck`, `npm run build`, `npm run dev`.
5. После локальной проверки выполни `git add src/App.tsx src/content/site.ts src/styles.css public/images`, `git commit -m "Update roadmap project images, PUNKDEPO stage and socials"` и `git push` в ветку, из которой настроен деплой.

## Важно

Данная сборка не была опубликована на VPS или отправлена в приватный GitHub-репозиторий автоматически.
